# 🏟️ میدان ایجنت‌ها (Agent Arena) — راهنما

لیگ معاملاتی **کاغذی (Paper Trading)**: ۵ شرکت‌کننده (۴ ایجنت + کمیسیون) روی صرافی انتخابی تو،
خودشان ارزهای پرقدرت را پیدا می‌کنند، با وزن‌های خودشان تحلیل می‌کنند و معامله باز می‌کنند.
معامله‌ها بین بازدیدها و redeployها **زنده می‌مانند** و تا TP/SL/تایم‌اوت مدیریت می‌شوند.
در پایان: کدوم ایجنت بهترین وین‌ریت و امتیاز را می‌گیرد؟ 🏆

## فایل‌های جدید

| فایل | نقش |
|---|---|
| `pages/4_Agent_Arena.py` | صفحه‌ی میدان (۳ تب: اسکن، پوزیشن‌های باز، لیدربورد) |
| `core/arena.py` | موتور: شبیه‌سازی معامله، امتیازدهی، لیدربورد، اسکن |
| `core/arena_store.py` | ذخیره‌سازی: Supabase `arena_trades` + fallback فایل محلی |
| `core/duel_engine.py` | موتور مشترک ایجنت‌ها (از صفحه دوئل استخراج شده — هیچ تغییر منطقی) |
| `sql/arena_setup.sql` | ساخت جدول در Supabase (یک‌بار اجرا شود) |
| `pages/3_Agents_Duel.py` | سبک شد — همان دوئل قبلی، ولی موتور را از `core/duel_engine.py` import می‌کند |

## راه‌اندازی (۲ دقیقه)

1. **SQL**: در Supabase → SQL Editor → محتوای `sql/arena_setup.sql` را اجرا کن.
   (تا وقتی اجرا نشده، آرنا خودکار روی فایل محلی کار می‌کند ولی با redeploy داده پاک می‌شود — خودش هشدار می‌دهد.)
2. **Deploy**: هیچ تنظیم جدیدی لازم نیست — `requirements.txt` تغییر نکرده.
3. صفحه‌ی جدید «🏟️ میدان ایجنت‌ها» را از منو باز کن و «🔎 شروع اسکن» را بزن.

## قواعد انصاف

- یک universe ارز، یک تایم‌فریم، کارمزد یکسان برای همه.
- ریسک ثابت **۱٪** ایکوییتی در هر معامله (ایکوییتی شروع: ۱۰٬۰۰۰$ کاغذی).
- حداکثر **۳ پوزیشن** همزمان برای هر شرکت‌کننده · سقف کل میدان: **۱۵**.
- هر نماد فقط یک پوزیشن باز برای هر شرکت‌کننده + cooldown **۱۰ کندلی** بعد از بستن معامله.
- شرط ورود هر ایجنت: امتیاز خودش از آستانه‌اش رد کند + بک‌تست خودش روی همان ارز سودده (PF>1) +
  موتور ستاپ walk-forward هم‌جهت + R:R ≥ ۱. کمیسیون با اجماع ۳/۴ وارد می‌شود.
- در هر کندل **اول استاپ چک می‌شود** (محافظه‌کارانه)، بعد تارگت‌ها.

## امتیازدهی

| نتیجه | امتیاز |
|---|---|
| TP3 کامل (نردبان کامل ≈ +۲R) | **+۵** |
| TP2 | **+۲** |
| TP1 و خروج با تریل | **+۱** |
| سر‌به‌سر | **۰** |
| استاپ (لیکویید ایجنت) | **−۱** |
| تایم‌اوت (بعد از ۱۰۰ کندل) | **±۰٫۵** |

وین‌ریت = بردها ÷ (بردها + باخت‌ها). با کمتر از ۱۰ معامله، وین‌ریت معنای آماری مطمئنی ندارد (در جدول علامت می‌خورد).

## مدیریت خروج (نردبانی)

- TP1 → استاپ به نقطه‌ی ورود (Breakeven) + ⅓ پوزیشن با سود ۱R بسته می‌شود
- TP2 → استاپ به TP1 + ⅓ دیگر با سود ۲R
- TP3 → ⅓ آخر با سود ۳R — نردبان کامل = ۲R واقعی
- معامله‌ی سرگردان بعد از **۱۰۰ کندل** با قیمت بازار بسته می‌شود (تایم‌اوت)

## نکته‌ی مهم

این لیگ **شبیه‌سازی کاغذی** است — معامله‌ها هر بار که صفحه باز شود با کندل‌های تازه پیش برده می‌شوند
(حداکثر هر ۶۰ ثانیه یک‌بار). هیچ پول واقعی و هیچ API کلیدی درگیر نیست.
