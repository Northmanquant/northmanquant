# 🏟️ میدان ایجنت‌ها (Agent Arena) — راهنما

لیگ معاملاتی **کاغذی (Paper Trading)** با اسکن دومرحله‌ای کل بازار:
۵ شرکت‌کننده (۴ ایجنت + کمیسیون) اول **کل بازار صرافی را غربال می‌کنند** (بدون سقف تعداد) تا قوی‌ترین ارزها پیدا شوند،
بعد همان برگزیدگان را با موتور و وزن‌های خودشان تحلیل عمیق می‌کنند و معامله باز می‌کنند.
معامله‌ها بین بازدیدها و redeployها **زنده می‌مانند** و تا TP/SL/تایم‌اوت مدیریت می‌شوند.
در پایان: کدوم ایجنت بهترین وین‌ریت و امتیاز را می‌گیرد؟ 🏆

## اسکن دومرحله‌ای (بدون عدد ثابت)

- **مرحله ۱ — غربالگری:** کل بازار صرافی در یک فراخوانی گرفته می‌شود؛ ارزهای مرده (گردش < ۰٫۵ میلیون دلار در روز) و استیبل‌کوین‌ها حذف می‌شوند. قدرت هر ارز = ۵۵٪ مومنتوم ۲۴ ساعته (قدرمطلق — پامپ و دامپ هر دو) + ۳۰٪ نقدینگی + ۱۵٪ دامنه‌ی نوسان.
- **مرحله ۲ — تحلیل عمیق:** هر چیزی که از صدک ۸۵ قدرت رد شود وارد موتور ایجنت‌ها می‌شود — تعداد برگزیدگان بسته به حال بازار دینامیک است، عدد دست‌ساز نیست (فقط سقف فنی ۶۰تایی برای محافظت از سهمیه‌ی API صرافی).

## قدرت فیلتر ورود (سه سطح)

- **شکارچی (پیش‌فرض)** — فیلتر ستاپ خاموش؛ ایجنت‌ها فقط با امتیاز و بک‌تست خودشان تصمیم می‌گیرند (فعال‌ترین حالت).
- **متعادل** — ستاپ تازه در ۶ کندل اخیر کافی است.
- **سخت‌گیر** — فقط ستاپ تازه + لبه‌ی walk-forward اثبات‌شده روی همان نماد (کم‌معامله ولی بی‌رحم).

در هر سه سطح، بقیه‌ی دروازه‌ها فعال‌اند: آستانه‌ی امتیاز هر ایجنت + بک‌تست سودده (PF>1) + R:R ≥ ۱ + ساختار پوزیشن.

## فایل‌های جدید

| فایل | نقش |
|---|---|
| `pages/4_Agent_Arena.py` | صفحه‌ی میدان (۷ تب: اسکن، پوزیشن‌های باز، هشدارها، اخبار، لیدربورد، بازپخش، اعتبار لبه) |
| `core/arena.py` | موتور: غربالگری کل بازار، شبیه‌سازی معامله، امتیازدهی، لیدربورد، اسکن |
| `core/arena_store.py` | ذخیره‌سازی: Supabase `arena_trades` + fallback فایل محلی |
| `core/duel_engine.py` | موتور مشترک ایجنت‌ها (فاکتورها، بک‌تست، ستاپ) |
| `core/replay.py` | بازپخش تاریخی میدان — همان دروازه‌ها روی کندل‌های گذشته (تب 🧪) |
| `core/edge.py` | موتور لبه — بازپخش چندپنجره‌ای، حکم ✅/⚠️/❌ هر ایجنت، گیت بنچ و کمیسیون وزن‌دار (تب ⚖️) |
| `sql/arena_setup.sql` | ساخت جدول در Supabase (یک‌بار اجرا شود) |
| `core/autopilot.py` + `.github/workflows/arena-autopilot.yml` | فاز ۶ — اتوپایلوت ۳۰ دقیقه‌ای بدون مرورگر |

## راه‌اندازی (۲ دقیقه)

1. **SQL**: در Supabase → SQL Editor → محتوای `sql/arena_setup.sql` را اجرا کن.
   (تا وقتی اجرا نشده، آرنا خودکار روی فایل محلی کار می‌کند ولی با redeploy داده پاک می‌شود — خودش هشدار می‌دهد.)
2. **Deploy**: هیچ تنظیم جدیدی لازم نیست — `requirements.txt` تغییر نکرده.
3. صفحه‌ی «🏟️ میدان ایجنت‌ها» را از منو باز کن و «🔎 اسکن کل بازار» را بزن (فیلتر ورود پیش‌فرض: شکارچی).

## قواعد انصاف

- یک تایم‌فریم، کارمزد یکسان برای همه (universe برگزیدگان غربالگری برای همه یکسان است).
- ریسک ثابت **۱٪** ایکوییتی در هر معامله (ایکوییتی شروع: ۱۰٬۰۰۰$ کاغذی).
- حداکثر **۳ پوزیشن** همزمان برای هر شرکت‌کننده · سقف کل میدان: **۱۵**.
- هر نماد فقط یک پوزیشن باز برای هر شرکت‌کننده + cooldown **۱۰ کندلی** بعد از بستن معامله.
- شرط ورود هر ایجنت: امتیاز خودش از آستانه‌اش رد کند + بک‌تست خودش روی همان ارز سودده (PF>1) +
  موتور ستاپ walk-forward هم‌جهت + R:R ≥ ۱. کمیسیون با اجماع وزنی وارد می‌شود
  (بدون دیتای لبه = همان ۳/۴ قدیمی؛ با حکم لبه: سودده ۱٫۲ · خنثی ۱٫۰ · زیان‌ده ۰٫۸ — مجموع ≥ ۳٫۰).
- ایجنتِ بنچ‌شده (حکم ❌ در گیت «بنچ زیان‌ده‌ها») معامله‌ی تازه باز نمی‌کند؛ پوزیشن‌های بازش طبق قواعد معمول مدیریت می‌شود.
- در هر کندل **اول استاپ چک می‌شود** (محافظه‌کارانه)، بعد تارگت‌ها.

## ⚖️ موتور لبه (فاز ۵)

دروازه‌های عادی فقط می‌پرسند «این ایجنت روی این ارز الان بک‌تست سودده دارد؟» — هیچ‌کدام نمی‌پرسند «خودِ این ایجنت تاریحاً سودده بوده؟».
تب «⚖️ اعتبار لبه» با یک بازپخش کامل روی کل تاریخچه، معامله‌های هر ایجنت را به پنجره‌های زمانیِ جدا (بر اساس کندل ورود) تفکیک می‌کند
و با قواعد ثابت حکم می‌دهد:

| حکم | شرط |
|---|---|
| ❌ زیان‌ده | ≥ ۱۲ معامله + انتظاری کل زیر −۰٫۱۰R + زیان در بیشتر از نیمِ پنجره‌های فعال |
| ✅ سودده | ≥ ۱۲ معامله + انتظاری کل بالای +۰٫۰۵R + PF کل > ۱ + هیچ پنجره‌ای بدتر از −۰٫۲۵R + زیان در حداکثر نیمِ پنجره‌ها |
| ⚠️ بی‌لبه | بقیه (نمونه‌ی کم یا مخلوط) — سقفِ مجاز است، نه تضمین |

- سه حالت گیت: خاموش · بنچ زیان‌ده‌ها (پیش‌فرض) · فقط سودده‌ها — فقط حکمِ تازه (زیر یک هفته) گیت را مسلح می‌کند.
- حکم‌ها در `arena_edge.json` ذخیره می‌شود (با redeploy پاک می‌شود — دوباره بازپخش بگیر).
- جهانِ بازپخش نمادهای انتخابی توست — شاهد آماری است، نه تضمین؛ جای شواهد زنده (دروازه‌ی ۱۰۰ معامله) را نمی‌گیرد.

## امتیازدهی

| نتیجه | امتیاز |
|---|---|
| TP3 کامل (نردبان کامل ≈ +۲R) | **+۵** |
| TP2 | **+۲** |
| TP1 و خروج با تریل | **+۱** |
| سر‌به‌سر | **۰** |
| استاپ (لیکویید ایجنت) | **−۱** |
| تایم‌اوت (بعد از ۱۰۰ کندل) | **±۰٫۵** |

وین‌ریت = بردها ÷ (بردها + باخت‌ها). با کمتر از ۱۰ معامله، وین‌ریت معنای آماری مطمئنی ندارد (در جدول علامت می‌خورد).

## مدیریت خروج (نردبانی)

- TP1 → استاپ به نقطه‌ی ورود (Breakeven) + ⅓ پوزیشن با سود ۱R بسته می‌شود
- TP2 → استاپ به TP1 + ⅓ دیگر با سود ۲R
- TP3 → ⅓ آخر با سود ۳R — نردبان کامل = ۲R واقعی
- معامله‌ی سرگردان بعد از **۱۰۰ کندل** با قیمت بازار بسته می‌شود (تایم‌اوت)

## 🤖 اتوپایلوت (فاز ۶)

میدان دیگر فقط وقتی صفحه‌ی اپ باز باشد زنده نیست — **GitHub Actions هر ۳۰ دقیقه** همان زنجیره را
بدون مرورگر اجرا می‌کند (`core/autopilot.py` + `.github/workflows/arena-autopilot.yml`):

پیش‌بردن پوزیشن‌های باز (TP/SL/تایم‌اوت) ← هشدار «بسته شد» ← رژیم بازار (ضدتکرار) ←
اسکن دومرحله‌ای کل بازار ← بازکردن معامله‌ی تازه با همان سهمیه/cooldown ← هشدار «باز شد»

**فعال‌سازی (۲ دقیقه):**

1. در GitHub ریپو: **Settings → Secrets and variables → Actions → New repository secret** — دو Secret:
   - `SUPABASE_URL` = آدرس پروژه (`https://xxxx.supabase.co`)
   - `SUPABASE_KEY` = کلید publishable (یا anon)
2. تب **Actions** → «Arena Autopilot» → **Run workflow** برای اجرای اولِ دستی.
3. تمام — از این لحظه هر ۳۰ دقیقه خودکار اجرا می‌شود (ریپو عمومی است؛ Actions رایگان و نامحدود).

**مشاهده و کنترل:** تب Actions → آخرین اجرا → خلاصه‌ی JSON در Step Summary.
توقف موقت: ⋯ → **Disable workflow**. حالت سبک فقط-مدیریت: در workflow مقدار `ARENA_SCAN` را `0` کنید.

**اجرای محلی:** `python -m core.autopilot` — با `SUPABASE_URL`/`SUPABASE_KEY` در محیط، روی سوپابیس
می‌نویسد؛ بدون آن‌ها روی فایل محلی (در Actions فایل محلی با هر اجرا پاک می‌شود — Secret الزامی است).
