# 📱 NorthmanQuant — اپ اندروید (Capacitor + GitHub Actions)

این پوشه یک **اپ اندروید واقعی (APK)** می‌سازد که اپ Streamlit تو را داخل یک WebView
نمایش می‌دهد. ساخت APK **کاملاً خودکار و رایگان** توسط GitHub Actions انجام می‌شود —
به هیچ کامپیوتر، اندروید استودیو یا نصب جاوا روی سیستم خودت نیاز نداری.

> ✅ این پایپ‌لاین به‌طور کامل تست شده و APK سالم می‌سازد.

## ✨ امکانات حرفه‌ای اپ
- **آیکون سفارشی** (از `assets/icon.png` خودکار در همه‌ی اندازه‌ها ساخته می‌شود)
- **اسپلش‌اسکرین** با لوگو هنگام باز شدن اپ (از `assets/splash.png`)
- **حالت تمام‌صفحه‌ی واقعی** و نوار وضعیت هماهنگ با تم تیره
- برای تغییر آیکون/اسپلش، فقط عکس‌های داخل پوشه‌ی `assets/` را عوض کن.

---

## 🧭 مرحله ۱ — لینک اپت را بگذار

فایل **`mobile-app/capacitor.config.json`** را باز کن و این خط را با لینک واقعی اپ
Streamlit‌ات عوض کن:

```json
"url": "https://REPLACE-WITH-YOUR-APP.streamlit.app",
```

مثلاً:

```json
"url": "https://northmanquant-xxxx.streamlit.app",
```

(در صورت تمایل می‌توانی `appName` و `appId` را هم تغییر دهی.)

---

## 🚀 مرحله ۲ — پوش کن و بگذار GitHub خودش بسازد

کل پروژه (همین مخزن) را روی GitHub بفرست:

```bash
git add .
git commit -m "add android app (capacitor + github actions)"
git push
```

به‌محض push، تب **Actions** در گیت‌هاب یک اجرای «Build Android APK» شروع می‌کند.

> اگر خودکار شروع نشد: به تب **Actions** برو → از منوی چپ **Build Android APK** →
> دکمه‌ی **Run workflow**.

---

## ⬇️ مرحله ۳ — APK را دانلود کن

۱. تب **Actions** → آخرین اجرای موفق (تیک سبز ✓) را باز کن
۲. پایین صفحه، بخش **Artifacts** → روی **`NorthmanQuant-APK`** بزن
۳. فایل زیپ دانلود می‌شود؛ بازش کن تا **`NorthmanQuant.apk`** را بگیری
۴. این فایل را روی گوشی اندروید بریز و نصب کن (باید «نصب از منابع ناشناس» را اجازه بدهی)

همین! حالا آیکون NorthmanQuant روی گوشی است و اپ تمام‌صفحه باز می‌شود.

---

## 🏷️ (اختیاری) نسخه‌ی رسمی با Release

اگر یک **Release** در گیت‌هاب بسازی (مثلاً تگ `v1.0.0`)، APK به‌طور خودکار به همان
Release پیوست می‌شود و لینک دانلود ثابت و قابل‌اشتراک می‌گیری که به هرکسی می‌دهی:

```bash
git tag v1.0.0
git push origin v1.0.0
```

سپس در گیت‌هاب → **Releases** → **Draft a new release** → تگ `v1.0.0` → **Publish**.

## 🔁 به‌روزرسانی اپ گوشی

نکته‌ی مهم: چون اپ فقط **پنجره‌ای به سایت Streamlit** است، هر تغییری که در
`app.py` بدهی و روی Streamlit Cloud دیپلوی شود، **بلافاصله در اپ گوشی هم دیده می‌شود** —
بدون نیاز به ساخت دوباره‌ی APK. فقط وقتی APK جدید لازم است که آیکون/نام/لینک عوض شود.

## ❓ سؤال‌های رایج

- **رایگان است؟** بله. GitHub Actions برای مخزن‌های عمومی کاملاً رایگان است.
- **اندروید استودیو لازم است؟** نه. همه‌چیز روی سرور گیت‌هاب ساخته می‌شود.
- **آیفون؟** ساخت IPA و انتشار در App Store نیاز به حساب ۹۹ دلاری اپل دارد. برای آیفون
  بهترین راه رایگان، نصب به‌صورت **PWA** است: در Safari لینک را باز کن →
  Share → «Add to Home Screen».
- **APK امضا شده؟** این یک APK **debug** است (برای نصب مستقیم عالی). برای انتشار در
  Google Play به APK/AAB امضاشده‌ی release نیاز است (می‌شود بعداً اضافه کرد).
- **اینترنت لازم است؟** بله، چون داده‌ها زنده از صرافی‌ها خوانده می‌شوند.
